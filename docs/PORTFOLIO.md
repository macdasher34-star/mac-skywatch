# Project summary for an employer or professional profile

## 100-word project overview

**Operation SKY WATCH 001 — Python Public-Data Quality Audit**  
Built and debugged a Python standard-library workflow in an isolated Ubuntu virtual machine to examine 10,010 published San Francisco police drone flight-log records. Implemented CSV validation, missing-field analysis, year/month aggregation, record grouping by case/event identifiers, and an HTML summary dashboard. Repaired a production-style date parser issue, verified source integrity using SHA-256, and reproduced a published finding of 447 criminal-investigation flight rows without call-type values in January–September 2026. Published a public GitHub Pages dashboard and documented the methodology, scope, uncertainty, and ethical limits of the work.
